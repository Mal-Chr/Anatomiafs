ANATOMIAFS REDESIGN
===================

Isi folder:
- index.html       : halaman utama
- saraf.html       : materi sistem saraf
- gerak.html       : materi sistem gerak
- hubungan.html    : hubungan sistem saraf dan sistem gerak
- quiz.html        : kuis interaktif
- style.css        : desain responsif, animasi, navigasi
- script.js        : menu mobile, transisi halaman, animasi reveal, dan kuis

Cara menjalankan:
1. Ekstrak semua file ke satu folder.
2. Buka index.html menggunakan browser.
3. Pastikan internet aktif agar Google Fonts dan gambar Wikimedia Commons dapat dimuat.

Catatan:
- Semua gambar konten dimuat dari Wikimedia Commons. Tidak ada gambar anatomi yang digambar sendiri dengan CSS, SVG, HTML, atau JavaScript.
- Bentuk dekoratif CSS yang tersisa hanya untuk layout, warna, bayangan, dan animasi antarmuka, bukan untuk menggantikan foto/ilustrasi anatomi.
- Gambar diambil dari URL Commons, jadi browser memerlukan koneksi internet.
- Lisensi tiap file dapat berubah atau memiliki syarat atribusi tersendiri. Periksa halaman sumber sebelum website dipublikasikan secara umum.
